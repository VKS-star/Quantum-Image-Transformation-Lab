= Quantum Image Transformation Lab

== FRQI brightness control for low-light photo enhancement

This single-notebook project studies whether FRQI quantum operations can
brighten genuinely underexposed photographs and how closely their
reconstructed images match normal-light references.

=== Practical use case

The primary application is *low-light photo enhancement*: a dim indoor
or night-time image is brightened to improve visibility. The primary
dataset is LOL (LOw-Light), which provides paired low-light inputs and
normal-light reference images captured from real scenes. This pairing
lets us measure whether each brightness operation moves the input toward
the desired exposure, rather than only comparing two transformations of
an unrelated image.

== 2. FRQI encoding and reconstruction

For a square image with side length `S = 2^n`, FRQI uses `2n` position
qubits and one colour qubit. Each pixel intensity `I_i` becomes an
angle `theta_i = (pi/2) * I_i/255`. The encoded state is

`|I> = 1/sqrt(S*S) * sum_i (cos(theta_i)|0> + sin(theta_i)|1>) tensor |i>`.

Hadamard gates create an equal superposition of pixel addresses. A
uniformly controlled `Ry(2 theta_i)` rotates the colour qubit by an
amount selected by each address. Readout estimates intensity from
`P(colour=1 | address=i) = sin(theta_i)^2`.

[source,ipython3]

# FRQI accepts square power-of-two grayscale arrays, with pixel addresses flattened row first.
def validate_image(image):
    """Check the assumptions required by the FRQI encoding used in this notebook."""
    a = np.asarray(image, dtype=float)
    if a.ndim != 2 or a.shape[0] != a.shape[1]:
        raise ValueError("FRQI input must be a square, single-channel image.")
    side = a.shape[0]
    if side < 2 or side & (side - 1):
        raise ValueError("Image side length must be a power of two (2, 4, 8, 16, ...).")
    if not np.isfinite(a).all() or a.min() < 0 or a.max() > 255:
        raise ValueError("Pixel values must be finite and within [0, 255].")
    return a

def image_to_angles(image):
    """Map 8-bit grayscale values to FRQI angles in [0, pi/2]."""
    image = validate_image(image)
    return (image.ravel() / 255.0) * HALF_PI

def angles_to_image(angles, side):
    """Convert decoded FRQI angles back to grayscale levels and restore image shape."""
    return np.clip(np.asarray(angles), 0, HALF_PI).reshape(side, side) * (255.0 / HALF_PI)

def position_qubits(side):
    """Return 2*log2(side), the number of qubits needed to address all pixels."""
    return 2 * int(np.log2(side))

def frqi_circuit(image):
    """Prepare |I>: Hadamards address pixels, then one uniformly controlled Ry encodes colour."""
    image = validate_image(image)
    side = image.shape[0]
    angles = image_to_angles(image)
    address_count = position_qubits(side)
    circuit = QuantumCircuit(address_count + 1, name=f"FRQI_{side}x{side}")
    colour = address_count
    circuit.h(range(address_count))
    circuit.append(UCRYGate([2 * float(theta) for theta in angles]), [colour] + list(range(address_count)))
    return circuit

def negative_gate(side):
    """An X on the colour qubit exchanges theta and pi/2-theta: intensity becomes 255-I."""
    circuit = QuantumCircuit(position_qubits(side) + 1)
    circuit.x(position_qubits(side))
    return circuit

def global_brightness_gate(side, increase):
    """A single global Ry adds the same angle offset to every pixel (additive brightness)."""
    circuit = QuantumCircuit(position_qubits(side) + 1)
    circuit.ry(increase * np.pi, position_qubits(side))
    return circuit

def controlled_multiplicative_gate(image, increase):
    """Apply per-pixel angle deltas to implement clipped I*(1+increase) brightness."""
    image = validate_image(image)
    side = image.shape[0]
    angles = image_to_angles(image)
    deltas = np.minimum(angles * increase, HALF_PI - angles)
    circuit = QuantumCircuit(position_qubits(side) + 1)
    circuit.append(UCRYGate([2 * float(delta) for delta in deltas]), [position_qubits(side)] + list(range(position_qubits(side))))
    return circuit

print("FRQI encoder and transformation circuits defined.")

== 3. Classical baselines, readout, and accuracy measures

Two brightness definitions are compared fairly with their matching
classical operations: (a) multiplicative `I*(1+p)` with
clipping, and (b) additive `I+255p` with clipping. The global
quantum rotation follows the additive angle rule and can wrap when an
angle exceeds `pi/2`; it does not perform clipping.

Exact reconstruction uses the statevector and isolates the
transformation. Shot reconstruction samples a finite number of complete
outcomes; at least some pixels may receive fewer observations. MAE and
PSNR measure pixel error, SSIM measures structural similarity, and state
fidelity measures the transformed quantum state against the ideal
encoded target.

[source,ipython3]
----
# Classical target transformations; clipping is the ordinary 8-bit image convention.
def classical_multiplicative(image, increase):
    return np.clip(np.asarray(image, float) * (1 + increase), 0, 255)

def classical_additive(image, increase):
    return np.clip(np.asarray(image, float) + 255 * increase, 0, 255)

def classical_negative(image):
    return 255 - np.asarray(image, float)

def decode_exact(state, side):
    """Recover each pixel from exact amplitudes (the colour bit is the most-significant bit)."""
    amplitudes = np.asarray(state.data).reshape(2, side * side)
    conditional_one = np.clip(np.abs(amplitudes[1]) ** 2 * (side * side), 0, 1)
    return angles_to_image(np.arcsin(np.sqrt(conditional_one)), side)

def decode_by_shots(state, side, shots, seed=0):
    """Sample the ideal measurement distribution and reconstruct from finite counts."""
    probabilities = np.abs(np.asarray(state.data)) ** 2
    counts = np.random.default_rng(seed).multinomial(shots, probabilities / probabilities.sum()).reshape(2, side * side)
    total = counts.sum(axis=0)
    conditional_one = np.divide(counts[1], total, out=np.zeros(side * side, dtype=float), where=total > 0)
    return angles_to_image(np.arcsin(np.sqrt(np.clip(conditional_one, 0, 1))), side)

def image_metrics(reference, estimate):
    """Return common full-reference image metrics for two same-sized grayscale arrays."""
    reference, estimate = np.asarray(reference, float), np.asarray(estimate, float)
    mse = float(np.mean((reference - estimate) ** 2))
    side = reference.shape[0]
    window = min(7, side if side % 2 else side - 1)
    return {"MAE": float(np.mean(np.abs(reference - estimate))),
            "PSNR_dB": 99.0 if mse < 1e-12 else float(10 * np.log10(255**2 / mse)),
            "SSIM": float(ssim(reference, estimate, data_range=255, win_size=window))}

def ideal_frqi_state(image):
    """Build the ideal FRQI state analytically, for state-fidelity comparisons."""
    theta = image_to_angles(image)
    return Statevector(np.concatenate([np.cos(theta), np.sin(theta)]) / np.sqrt(theta.size))

print("Baselines, reconstruction methods, and image metrics defined.")

# Construct synthetic test patterns with known pixels and inspect the FRQI invariants.
synthetic_images = {
    "horizontal gradient": np.tile(np.linspace(0, 220, 4), (4, 1)),
    "checkerboard": (np.indices((4, 4)).sum(axis=0) % 2) * 220.0,
    "center square": np.pad(np.full((2, 2), 180.0), 1),
}
verification_rows = []
for name, image in synthetic_images.items():
    theta = image_to_angles(image)
    state = Statevector(frqi_circuit(image))
    expected_amplitudes = np.vstack([np.cos(theta), np.sin(theta)]) / 4.0
    actual_amplitudes = state.data.reshape(2, 16)
    recovered = decode_exact(state, 4)
    negative_state = state.evolve(negative_gate(4))
    verification_rows.append({
        "pattern": name,
        "state_norm": np.linalg.norm(state.data),
        "largest_amplitude_error": np.max(np.abs(actual_amplitudes - expected_amplitudes)),
        "decode_MAE": np.mean(np.abs(recovered - image)),
        "negative_max_error": np.max(np.abs(decode_exact(negative_state, 4) - classical_negative(image))),
    })
verification = pd.DataFrame(verification_rows)
display(verification.round(12))
assert np.allclose(verification["state_norm"], 1.0, atol=1e-10), "FRQI state must be normalized."
assert verification["largest_amplitude_error"].max() < 1e-10, "Encoded amplitudes do not match the FRQI equation."
assert verification["decode_MAE"].max() < 1e-8, "Exact decoder failed to recover the synthetic image."
assert verification["negative_max_error"].max() < 1e-4, "Quantum negative does not match 255-image within numerical precision."
print("PASS: synthetic 4x4 FRQI encoding and negative checks.")

def prepare_grayscale(source, side):
    """Convert an uploaded image to luminance, center-crop, and area-resize to side x side."""
    if isinstance(source, Image.Image):
        pil = source
    else:
        pil = Image.open(io.BytesIO(source))
    grayscale = pil.convert("L")
    width, height = grayscale.size
    edge = min(width, height)
    grayscale = grayscale.crop(((width-edge)//2, (height-edge)//2, (width-edge)//2+edge, (height-edge)//2+edge))
    return np.asarray(grayscale.resize((side, side), Image.Resampling.BOX), dtype=float)

# Dataset helpers: MNIST is downloaded automatically; LOL can be fetched through gdown or loaded locally.
def cached_download(url, filename, attempts=3):
    """Download a file safely into the local cache, retrying incomplete transfers."""
    path = CACHE / filename
    temporary_path = CACHE / (filename + ".part")
    if path.exists() and path.stat().st_size > 0:
        return path
    request = urllib.request.Request(url, headers={"User-Agent": "QuantumImageBrightnessNotebook/1.0"})
    last_error = None
    for attempt in range(1, attempts + 1):
        try:
            print(f"Downloading {filename} (attempt {attempt}/{attempts}).")
            with urllib.request.urlopen(request, timeout=90) as response:
                expected = response.headers.get("Content-Length")
                expected = int(expected) if expected else None
                received = 0
                with open(temporary_path, "wb") as target:
                    while True:
                        block = response.read(1024 * 1024)
                        if not block:
                            break
                        target.write(block)
                        received += len(block)
            if expected is not None and received != expected:
                raise IOError(f"Incomplete download: {received:,} of {expected:,} bytes.")
            temporary_path.replace(path)
            return path
        except Exception as error:
            last_error = error
            temporary_path.unlink(missing_ok=True)
            if attempt < attempts:
                time.sleep(attempt)
    raise IOError(f"Could not download {filename}; check internet access or add the file to {CACHE}.") from last_error

IMAGE_SUFFIXES = {".png", ".jpg", ".jpeg", ".bmp", ".tif", ".tiff"}
LOW_DIR_NAMES = {"low", "input", "lowlight", "low_light"}
REFERENCE_DIR_NAMES = {"high", "normal", "gt", "ground_truth", "normal_light", "well_lit"}

def _image_members_from_zip(archive):
    """Find matching low/reference image files inside the LOL test archive."""
    names = [name for name in archive.namelist() if Path(name).suffix.lower() in IMAGE_SUFFIXES]
    files = set(names)
    pairs = []
    for low_name in names:
        parts = list(Path(low_name).parts)
        low_positions = [i for i, part in enumerate(parts[:-1]) if part.lower() in LOW_DIR_NAMES]
        if not low_positions:
            continue
        i = low_positions[-1]
        parent, filename = parts[:i], parts[-1]
        stem = Path(filename).stem.lower()
        for reference_folder in REFERENCE_DIR_NAMES:
            candidate = str(Path(*parent, reference_folder, filename))
            if candidate in files:
                pairs.append((low_name, candidate))
                break
            # Match a reference image by stem if the archive uses a different extension or case.
            prefix = str(Path(*parent, reference_folder)).lower().rstrip("/") + "/"
            matches = [name for name in names if name.lower().startswith(prefix) and Path(name).stem.lower() == stem]
            if matches:
                pairs.append((low_name, matches[0]))
                break
    return sorted(set(pairs), key=lambda pair: pair[0].lower())

def _read_lol_directory(root):
    """Read paired images from the usual eval15/low+high or Test/low+normal layout."""
    pairs = []
    for low_dir in root.rglob("*"):
        if not low_dir.is_dir() or low_dir.name.lower() not in LOW_DIR_NAMES:
            continue
        sibling_dirs = [path for path in low_dir.parent.iterdir() if path.is_dir() and path.name.lower() in REFERENCE_DIR_NAMES]
        if not sibling_dirs:
            continue
        low_files = sorted(path for path in low_dir.iterdir() if path.is_file() and path.suffix.lower() in IMAGE_SUFFIXES)
        for reference_dir in sibling_dirs:
            ref_files = sorted(path for path in reference_dir.iterdir() if path.is_file() and path.suffix.lower() in IMAGE_SUFFIXES)
            ref_by_stem = {path.stem.lower(): path for path in ref_files}
            matched = [(low, ref_by_stem[low.stem.lower()]) for low in low_files if low.stem.lower() in ref_by_stem]
            if not matched and len(low_files) == len(ref_files):
                matched = list(zip(low_files, ref_files))
            for low_path, ref_path in matched:
                # Keep the held-out evaluation split only.
                ancestors = {part.lower() for part in low_path.parts}
                if ancestors.intersection({"eval15", "test", "testing", "eval"}):
                    low_img = np.asarray(Image.open(low_path).convert("RGB"))
                    ref_img = np.asarray(Image.open(ref_path).convert("RGB"))
                    pairs.append((low_img, ref_img, low_path.name))
    return pairs

# Select balanced examples from labeled datasets.
def balanced_sample(images, labels, per_class, class_count=10):
    """Return a balanced set containing the first per_class examples of each label."""
    selected = [int(i) for label in range(class_count) for i in np.flatnonzero(labels == label)[:per_class]]
    if len(selected) != class_count * per_class:
        raise ValueError("Not enough examples for a balanced sample.")
    return [images[i] for i in selected], labels[selected]

def grayscale_image(image):
    """Convert grayscale or color pixels to 8-bit grayscale for FRQI."""
    array = np.asarray(image)
    if array.ndim == 2:
        return Image.fromarray(array.astype(np.uint8)).convert("L")
    return Image.fromarray(array.astype(np.uint8)).convert("RGB").convert("L")

def resize_dataset(images, side):
    """Center-crop and area-resize source images to square grayscale FRQI arrays."""
    result = []
    for image in images:
        gray = grayscale_image(image)
        width, height = gray.size
        edge = min(width, height)
        square = gray.crop(((width-edge)//2, (height-edge)//2, (width-edge)//2+edge, (height-edge)//2+edge))
        result.append(np.asarray(square.resize((side, side), Image.Resampling.BOX), dtype=float))
    return result

== 8. Benchmark runner: brightness and negative

For each image and each brightness percentage, the circuit is prepared
from the original image and transformed. Multiplicative quantum
brightness is compared to `clip(I*(1+p))`; global `Ry`
brightness is compared to `clip(I+255p)`. We record ideal-state
fidelity and exact reconstruction error. For one sample per dataset/size
we also compare finite-shot reconstruction, using a fixed number of
total outcomes per pixel on average. Negative runs are checked against
`255-I`.

[source,ipython3]
----
# Keep these functions explicit so every metric column has a defined comparison target.
INCREASES = (0.10, 0.25, 0.50)
SHOTS_PER_PIXEL = 2048

def evaluate_brightness(images, side, dataset_name, shot_examples=1):
    """Evaluate both quantum brightness rules against their paired classical transformations."""
    rows = []
    for image_index, image in enumerate(images):
        base = Statevector(frqi_circuit(image))
        theta = image_to_angles(image)
        for increase in INCREASES:
            cases = [
                ("controlled multiplicative", controlled_multiplicative_gate(image, increase), classical_multiplicative(image, increase)),
                ("global additive", global_brightness_gate(side, increase), classical_additive(image, increase)),
            ]
            for method, gate, target in cases:
                transformed = base.evolve(gate)
                exact = decode_exact(transformed, side)
                score = image_metrics(target, exact)
                row = {"dataset": dataset_name, "side": side, "image_index": image_index,
                       "increase": f"+{increase:.0%}", "method": method,
                       "state_fidelity": state_fidelity(transformed, ideal_frqi_state(target)),
                       "saturated_fraction": float(np.mean(np.asarray(image) * (1+increase) > 255)), **score}
                if image_index < shot_examples:
                    shot = decode_by_shots(transformed, side, SHOTS_PER_PIXEL * side * side, seed=2026 + image_index)
                    row["shot_MAE"] = image_metrics(target, shot)["MAE"]
                rows.append(row)
    return pd.DataFrame(rows)

def evaluate_negative(images, side, dataset_name):
    """Compare X-gate reconstruction against the exact classical image negative."""
    rows = []
    for image_index, image in enumerate(images):
        source = Statevector(frqi_circuit(image))
        transformed = source.evolve(negative_gate(side))
        target = classical_negative(image)
        rows.append({"dataset": dataset_name, "side": side, "image_index": image_index,
                     "state_fidelity": state_fidelity(transformed, ideal_frqi_state(target)),
                     **image_metrics(target, decode_exact(transformed, side))})
    return pd.DataFrame(rows)

def dataset_summary(results):
    """Aggregate errors by data source, grid size, transformation, and requested increase."""
    keys = [key for key in ("dataset", "side", "method", "increase") if key in results.columns]
    return results.groupby(keys).mean(numeric_only=True).round(4)

== 12A. Transform, reconstruct, recover the original, and compare quality

This experiment separates two questions. **Forward reconstruction:** does the decoded quantum output match the intended classical transformation? Compare against the clipped classical brightness target (or the classical negative), not the original dark input. **Recovery back to the original:** undo the operation on the transformed output and compare with the original, same-size grayscale input.

For +10%, +25%, +50% brightness, recovery divides the transformed pixel values by the corresponding gain. The quantum recovery circuit is built only from the decoded transformed image and the known gain, never from saved original pixel angles. Thus saturated highlights cannot be secretly recovered using the original encoding information. This division is an inverse-operation test, not a new user-facing darkening condition. For the negative, apply `255 − value` again classically, or another X gate in the reconstructed quantum branch.

Compare classical floating-point processing, ideal exact FRQI reconstruction, and finite-shot FRQI readout with the same preprocessing and grayscale resolution. Classical rounding is not introduced before the metrics, and exact-state access is explicitly privileged simulator access. The finite-shot branch includes a readout after the forward transform, re-encoding of that measured image, and a second sampled readout after recovery. It uses two shot budgets; it is not equally cheap as exact readout.

MAE lower is better; PSNR and SSIM higher are better. “Tie” means numerical agreement within 1e−4 gray levels, not superiority of one method. In this ideal controlled transformation, classical and exact quantum processing should agree. Recovery quality measures how much information survives the operation, not whether the low-light photograph has been restored to its correct real-world exposure. No paired normal-light references are available for the 12 supplied photos.

[source,ipython3]

def comparison_quality(reference, estimate):
    score = image_metrics(reference, estimate)
    mse = float(np.mean((np.asarray(reference, float)-np.asarray(estimate, float))**2))
    score["PSNR_dB"] = float("inf") if mse < 1e-12 else float(10*np.log10(255**2/mse))
    return score

def recover_transformed_image(transformed_image, condition, amount=0.0, use_shots=False, seed=2026):
    side = transformed_image.shape[0]
    state = Statevector(frqi_circuit(transformed_image))
    if condition == "negative":
        recovered_state = state.evolve(negative_gate(side))
    else:
        inverse_change = 1/(1+amount)-1
        recovered_state = state.evolve(controlled_multiplicative_gate(transformed_image, inverse_change))
    if use_shots:
        return decode_by_shots(recovered_state, side, SHOTS_PER_PIXEL*side*side, seed=seed)
    return decode_exact(recovered_state, side)

== 13. Image-size effect and circuit resources

FRQI uses `2 log2(S)+1` qubits for an `S×S` grayscale image, while
its state contains `S²` pixel amplitudes. The multiplexed preparation
and per-pixel controlled brightness operations require address-dependent
logic whose cost grows with pixel count. The one-gate global rotation
and negative stay constant in gate count, but this alone does not give
an end-to-end speed advantage: loading and reading all pixel values
remain costly.

== 14. Finite-shot readout: more measurements, lower sampling error

Exact simulation gives ideal probabilities; a quantum measurement
returns samples. The following experiment measures one 16×16 photo
negative with progressively larger shot budgets and repeats each budget
several times. Error should generally decrease as the sample count
rises, though individual points fluctuate. Each outcome picks an address
as well as a colour bit, so total shots are shared across all pixels.

# Measure one transformed image repeatedly at increasing total shot budgets.

== Notes for this focused revision

The 12 user-supplied scenes have no aligned normal-light references. Exact agreement with a classical brightness operation verifies the circuit, not restoration of correct exposure. A 50% increase may still leave the darkest regions dim. The global Ry is the original additive demonstration and can fold beyond π/2 instead of clipping; the pixel-controlled multiplicative method is the primary classical comparison.

This is noiseless classical statevector simulation. Small 8×8 and 16×16 grayscale grids lose detail; the original source photo itself is retained without a blur filter. Exact amplitudes are privileged simulator access, and finite-shot outputs are ideal simulated sampling, not hardware measurements. No end-to-end quantum speedup or deblurring capability is claimed.
